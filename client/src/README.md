# 文件管理界面

页面采用 Finder 式三栏工作区：左侧分类，中间搜索、排序与文件列表，右侧常驻预览和元数据。
分类依据文件名后缀优先判定（缺失或未知后缀时回落到 Content-Type），覆盖图片、文档、音视频、压缩包、安装包、代码/文本、数据库/备份和其他。
列表支持方向键移动、空格多选、回车查看完整信息和 Delete 删除；文件可直接拖入工作区上传。
上传对话框、详情和删除确认按职责拆分；上传直接发送浏览器文件对象并显示实时进度，删除部分失败时只重试未完成项。
# 可分享视图

文件页使用通用壳的 `use_page_url_state("file-list")`，分类、搜索与排序分别对应 `view.category`、`view.q`、`view.sort`；默认分类与排序省略。筛选点击创建历史节点，连续搜索输入合并为一个节点，非法枚举值原地规范化。列表滚动容器以 `data-url-scroll="files-list"` 接入壳层的滚动恢复。批量勾选、上传草稿和删除确认不进入分享链接。
